# 📊 班级二课分统计工具（ClassScore）

一个跑在本地电脑上的小网页工具，专门解决**"活动名单对不上班级总名单"**这件烦人事：

> 微信群里复制的名单是 `张三、李 四、王五`，班级 Excel 里写的是 `李四`；
> 还有错别字、括号备注、`以上同学请核对` 之类的废话……
> 手动对一遍要半小时，还容易看漏。

本工具把这些乱七八糟的文本清洗成干净姓名，自动**模糊匹配**到班级总名单，
把每个人参加过的活动**横向拆成一个个格子**，最后**一次性导出汇总 Excel**。

> 🆕 **批量版**：上传一次总名单，然后连着添加任意多个活动（青年大学习、运动会志愿者、班级团建……），
> 最后点一次"一键生成汇总 Excel"。参加 3 个活动的同学，会占 3 个格子：
>
> | 姓名 | 学号 | 活动1 | 活动2 | 活动3 |
> | --- | --- | --- | --- | --- |
> | 张三 | 20230101 | 青年大学习 | 运动会志愿者 | 班级团建 |
> | 李四 | 20230102 | 青年大学习 | | |
>
> 一个活动一个格子，没参加的格子**彻底留空**，绝不拼成 `青年大学习, 运动会志愿者`，也绝不合并单元格。

## ✨ 功能

| 功能 | 说明 |
| --- | --- |
| 📂 上传班级总名单 | 支持 `.xlsx / .xlsm`，自动识别"姓名"列（列名不同也可以手动选）**，只需上传一次** |
| 🧺 批量录入多个活动 | 填活动名 + 粘贴名单 → 点"添加到待统计列表"，可以反复添加；活动列表暂存在 `st.session_state` 里，中途改阈值、翻看名单都不会丢 |
| 🗂 待统计活动列表 | 表格列出已添加的每个活动、提取到的人数、自动匹配数和待核对数，方便核对；支持删除单个活动或一键清空 |
| 📋 粘贴活动名单 | 直接从微信聊天记录 Ctrl+V，换行、顿号、逗号、分号、`@所有人`、`以上同学`、表情符号都能处理 |
| 🧹 智能姓名提取 | 自动还原 `李 四 → 李四`，也能把 `张三 李四` 拆成两个人；像 `张三李四王五` 这种连在一起的会按 2 字规则切开并给出提醒 |
| 🔍 模糊匹配 | 基于 `rapidfuzz`（或 `thefuzz`）计算相似度，阈值可在侧边栏调节（默认 **85%**），对每个活动依次匹配 |
| 🖐 人工核对 | 低于阈值的名字**不会**自动匹配，会按活动分组列出来，并给出最接近的 3 个候选 + 相似度，你点一下下拉框即可确认 |
| ➕ 活动分列 | 一个人参加多个活动时，横向动态增加 `活动1`、`活动2`…… 每个活动单独占一个格子，格子里写活动名称；没参加就留空（重复的活动名不会重复写入） |
| ✏️ 表格内直接改 | 结果预览用的是可编辑表格，每个活动格子都能随手改，改完再下载 |
| ⬇️ 导出 Excel | 一键导出两个工作表：**统计结果**（完整名单 + 活动1/活动2…… 每个活动单独一格）和 **匹配明细**（带"活动名称"列，每个名字怎么匹配的一目了然） |
| 🎨 不污染原格式 | 导出**不加任何颜色、加粗、边框、冻结窗格**，纯白底；基础信息列的名称和顺序与原表完全一致，活动列追加在最后，也不会多出索引列 |
| 🔒 数据不出本机 | 全部在本地运行，名单不上传任何服务器 |

## 🚀 快速开始（Windows）

### 方式一：双击运行（推荐，小白友好）

1. 安装 [Python 3.9+](https://www.python.org/downloads/)（推荐 3.10~3.13；3.14 部分依赖可能还没有现成安装包），安装时**务必勾选 `Add Python to PATH`**。
2. 双击项目里的 **`run.bat`**。
3. 第一次运行会自动创建虚拟环境并安装依赖（需要几分钟，要联网）。
4. 浏览器自动打开 <http://localhost:8501>，开始使用。

### 方式二：手动命令行

```bat
:: 1. 进入项目目录
cd /d E:\你的路径\ClassScore

:: 2. 创建虚拟环境
python -m venv .venv

:: 3. 激活虚拟环境
.venv\Scripts\activate

:: 4. 安装依赖（国内加清华镜像，快很多）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

:: 5. 启动
streamlit run app.py
```

浏览器会自动打开 <http://localhost:8501>。想停止：在命令行窗口按 `Ctrl + C`。
想换端口：`streamlit run app.py --server.port 8502`。

### 📦 关于下载源（国内必看）

依赖默认走**清华镜像** `https://pypi.tuna.tsinghua.edu.cn/simple`，
不走官方 PyPI（国内直连经常几 KB/s，看起来就像"卡住不动"）。

- 想换源：改 `run.bat` 里的 `CS_PIP_INDEX` 这一行即可，
  比如阿里云 `https://mirrors.aliyun.com/pypi/simple/`。
- 想改回官方源：`set "CS_PIP_INDEX=official"`。
- 装依赖时只接受**现成的安装包**（pip 的 `--only-binary=:all:`），
  不允许 pip 去编译源码——Windows 上一般没有 C++ 编译器，
  一旦它开始编源码就会"卡很久然后失败"，这是很常见的坑。

## 🧭 使用步骤

1. **准备班级总名单**（`.xlsx`），至少包含一列姓名：

   | 姓名 | 学号 | 备注 |
   | --- | --- | --- |
   | 张三 | 20230101 | |
   | 李四 | 20230102 | |

2. 打开网页 → 上传这个 Excel（**整个过程只需要上传一次**，选好工作表和姓名列）。
3. 在「② 添加活动」区域里填**活动名称**、粘贴**这个活动的微信名单**，例如：

   ```
   【活动名单】张三、李 四、王五
   以上同学请于周三下午到体育馆集合 @所有人
   ```

   然后点 **➕ 添加到待统计列表**。输入框会自动清空，接着填下一个活动即可。
4. 有几个活动就重复几次第 3 步。下面的「③ 待统计活动列表」会用表格列出
   已添加的活动、提取到多少人、自动匹配多少、待核对多少，方便你核对；
   加错了可以删除单个活动，也可以一键清空重来。
5. 点 **🚀 一键生成汇总 Excel**，程序会依次对每个活动做模糊匹配。
6. 如果有低分名字，会**按活动分组**列在「④ 需要人工核对」里，
   为每个可疑名字选择对应同学（最像的排在最前），或保持"忽略"。
7. 检查「⑤ 汇总结果」表格：一行一个学生，每个活动单独一个格子（`活动1`、`活动2`……），
   格子里直接写活动名称，没参加的格子是空的。格子内容可以直接编辑。
   还能切换"活动列怎么排"：**按活动对齐**（默认，第 1 列永远是第 1 个添加的活动）
   或**按人依次填**（每行从 `活动1` 开始，依次写他参加的活动）。
8. 点 **⬇️ 下载汇总 Excel**，得到一份包含所有活动的汇总名单。

> ⚠️ **待添加的活动只存在浏览器内存里**：按 `F5` 刷新页面或关掉标签页就会清空，
> 所以请一口气把活动加完、生成、下载。（这是 Streamlit 的机制，不是 bug。）

> 💡 **下一次统计新活动时**：把班级总名单再上传一次，重新添加这次的活动即可。
> 如果上传的表里已经有上次导出的"活动名称"列或"活动1/活动2…"列，
> 程序会丢掉这些旧活动列、按本次统计重新生成，姓名/学号等基础信息不受影响。

## ⚙️ 参数说明（侧边栏）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 相似度阈值 | 85 | 越高越严格、越不容易误匹配，但需要人工核对的名字变多。推荐 80~90 |
| 相似度算法 | 严格 ratio | 换成"宽松 WRatio"能容忍漏字/错别字，但更容易误匹配，务必看匹配明细 |
| 最短/最长字数 | 2 / 4 | 中文姓名一般 2~4 字；如果班里有 5 字姓名的少数民族同学，把最长改成 5 |
| 空格怎么处理 | 智能识别 | `李 四 → 李四`；同时 `张三 李四 → 张三 / 李四` |
| 保留英文/拼音名字 | 关 | 名单里有英文名时勾上 |
| 自动切分超长汉字串 | 开 | `张三李四王五 → 张三 / 李四 / 王五`（会提示你核对） |

**为什么错别字经常跑到"人工核对"里？**
名字只有 2~3 个字时，错一个字相似度就只有 60~75 分，不会达到 85 分。
这是**故意的保护**：二课分统计宁可比对一下，也不能张冠李戴。
名字越长，模糊匹配越容易自动通过（例如 7 个字错 1 个仍有 85 分）。

## 📁 目录结构

```
ClassScore/
├── app.py               # 主程序（Streamlit 网页 + 数据处理逻辑）
├── launcher.py          # 启动助手：建虚拟环境、装依赖、启动网页（中文提示都在这）
├── run.bat              # Windows 双击启动（纯英文，见下方说明）
├── .streamlit/
│   └── config.toml      # 项目级配置：不问邮箱、不上报使用统计（重要）
├── requirements.txt     # 依赖清单
├── 示例班级名单.xlsx     # 示例名单，可用于试跑
├── README.md
└── .gitignore
```

> ⚠️ **`.streamlit/config.toml` 不要删！**
> Streamlit 首次运行会在终端里问 `Welcome to Streamlit! ... Email:`，
> 直接回车（空邮箱）会被判为无效并以退出码 **-1** 结束进程 ——
> 这就是"双击 run.bat 后窗口一闪而过、网页没起来"的原因。
> 这个文件里的 `showEmailPrompt = false` 就是关掉它的开关
> （`run.bat` 的环境变量和 `launcher.py` 的命令行参数是另外两道保险）。

> ⚠️ **为什么 run.bat 里一个中文都没有？**
> `cmd.exe` 解析 `.bat` 文件用的是系统 ANSI 代码页（中文 Windows 是 GBK）。
> 如果 `.bat` 里直接写 UTF-8 中文，cmd 会把中文字节切碎，
> 出现类似 `'"Add Python to PATH" 不是内部或外部命令` 的怪错误。
> 所以 `.bat` 只保留纯英文，所有中文提示都放在 `launcher.py` 里由 Python 输出。
> **改这个 .bat 时请务必继续只用英文/ASCII。**

## 🧰 技术栈

- **[Streamlit](https://streamlit.io/)** — 本地网页界面
- **[pandas](https://pandas.pydata.org/)** — 表格数据处理
- **[openpyxl](https://openpyxl.readthedocs.io/)** — 读写 `.xlsx`（导出时**不加任何样式**，纯数据、纯白底）
- **[rapidfuzz](https://github.com/rapidfuzz/RapidFuzz)** — 模糊匹配（首选，C++ 实现，快）
- **[thefuzz](https://github.com/seatgeek/thefuzz) + [python-Levenshtein](https://github.com/maxbachmann/Levenshtein)** — 备选实现
- 都没有时自动退化为标准库 `difflib`，程序依然能跑

## ❓ 常见问题

**Q：安装依赖卡在"正在安装依赖"很久没反应？**
三个常见原因，按顺序排查：
1. **在从官方 PyPI 下载**（国内直连很慢）。本项目的 `run.bat` 已经默认改用清华镜像，
   想换源改 `CS_PIP_INDEX` 那一行即可。
2. **pip 在编源码**。Windows 上没装 C++ 编译器时，编源码必然失败而且很慢。
   现在装依赖只接受现成的安装包（`--only-binary=:all:`），遇到没有安装包的包会**立刻报错**，
   而不是默默卡住。
3. **Python 版本太新**（例如 3.14），某个依赖还没有对应的安装包。
   报错里会点名是哪个包，这时装个 **Python 3.12**，删掉 `.venv` 后重新双击 `run.bat` 最稳。

**Q：`pip install python-Levenshtein` 报错（要装 Visual C++ 编译器）？**
它默认已经**不装**了（`requirements.txt` 里注释掉了）：
程序优先用 `rapidfuzz`，其次 `thefuzz`，都没有还能退化成标准库 `difflib`。
确实想装就把那行的 `#` 去掉。

**Q：双击 run.bat 一闪而过？**
两个原因，现在都处理了：
1. **Streamlit 首次运行问邮箱**（`Welcome to Streamlit! ... Email:`）。
   直接回车等于提交空邮箱，被判为无效后 Streamlit 用**退出码 -1** 结束进程；
   而 cmd 的 `if errorlevel 1` 认不出负数，于是窗口直接关了、什么提示都没有。
   现在 `.streamlit/config.toml` + 环境变量 + 命令行参数三处都关掉了这个询问，
   另外 run.bat 改成用字符串比较退出码，**最后一定 `pause`**，
   就算真出错窗口也会停住让你看报错。
2. **Python 没装好或没加入 PATH**。用 `python --version` 在命令行验证一下，
   run.bat 检测不到 Python 时也会给出英文提示并停住等你看。

**Q：还是被问了邮箱 / 想手动确认这个开关？**
确认项目目录里有 `.streamlit/config.toml`，内容是：

```toml
[server]
showEmailPrompt = false

[browser]
gatherUsageStats = false
```

想检查实际生效的值，可以在项目目录执行：

```bat
.venv\Scripts\python.exe -m streamlit config show
```

真要手动应答邮箱提示时，**不要按回车**，随便填一个 `a@b.com` 回车即可，
之后 Streamlit 会把凭据存到 `C:\Users\你的用户名\.streamlit\credentials.toml`，不会再问。

**Q：双击后提示 `'"Add Python to PATH"' 不是内部或外部命令`？**
这是**旧版 run.bat** 的编码问题（cmd 用 GBK 解析 .bat 里的 UTF-8 中文）。
本仓库的 run.bat 已经改成纯英文 + 中文提示交给 `launcher.py` 输出了，
如果你改过 run.bat，请注意别在 .bat 里写中文。

**Q：上传后提示找不到"姓名"列？**
页面会把你表格里的列名列出来，选一个正确的即可，其它列会原样保留。

**Q：班级里有重名同学怎么办？**
工具会弹黄色警告，并且把活动同时记到所有同名同学名下；请到"匹配明细"里核对，
或在结果表格里手动修改对应的活动格子。

**Q：导出的表格会不会改我的原格式？**
不会。导出的是**纯数据**：不设背景色、不加粗、不加边框、不冻结首行、不自动筛选、
不改列宽。基础信息列（姓名、学号……）的列名和列顺序保持不变，活动列追加在最后，
也不会多出 pandas 的索引列（0、1、2…）。原表里没有表头的列照样保持空白。
程序**从不合并单元格**，一个活动只占一个格子。

**Q：想去掉某人本次活动记录？**
在结果预览表格里直接删掉那个活动格子里的内容即可（表格可编辑）；没参加的格子本来就是空的。

**Q：支持 `.xls` 老格式吗？**
不支持，请在 Excel 里"另存为 `.xlsx`"。

**Q：粘贴的通知句子（比如"以上同学请于周三到体育馆集合"）会怎样？**
工具会把"以上同学""请""集合"这类内容识别为**通知/废话**并自动跳过，
不会硬拆成"请于""周三"这种假名字；同时会在页面上给出黄色提示，
告诉你跳过了哪一段。如果它误跳过了一串连写的名字，
用顿号或空格把它们隔开再粘贴即可。

**Q：为什么有的人名没被自动匹配上？**
看页面上的"匹配明细"表：每一行都写清楚了是精确匹配、模糊匹配还是待核对。
名字只有 2~3 个字时，错一个字相似度就会掉到 60~75 分，低于 85 的阈值，
这时需要你在"人工核对"里点一下下拉框。

**Q：一次能批量统计几个活动？**
没有数量限制，加几十个都行（每个活动添加时都会立刻清洗一次名单）。
活动列表存在 `st.session_state` 里，所以中途改阈值、切换相似度算法、
翻看总名单都不会丢。

**Q：刷新页面后待统计的活动不见了？**
是的，这是 Streamlit 的机制：待统计列表只保存在当前浏览器标签页的内存里，
按 `F5` 或关掉标签页就会清空。请一口气把活动加完、生成、下载。
（如果你希望连刷新都不丢，需要把列表写到本地文件或数据库，可以再找我加。）

**Q：同一个活动不小心加了两次会怎样？**
不会重复统计：同名活动会把第二次粘的名单**自动并入**第一条
（方便把一份很长的名单分两次粘贴），汇总时该活动名对同一个人也只记一次。

**Q：Python 版本有要求吗？**
建议 **Python 3.10 ~ 3.13**（推荐 3.12）。3.14 也能用，但万一某个依赖还没有
对应的安装包，`pip install` 会明确报出是哪个包，这时换 3.12 最省事。

**Q：同学姓名会泄露吗？**
不会。程序全部在你电脑本地运行，不联网、不上传。
`.gitignore` 也默认忽略了 `*.xlsx`，避免把含姓名的文件推到 GitHub。
